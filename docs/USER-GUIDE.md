## 基本的な使い方

### 最初のコマンド実行

1. **Minecraftの準備**
   - ワールドを作成またはサーバーに参加
   - Modが正常にロードされていることを確認

2. **接続テスト**
   ```javascript
   // WebSocketクライアントまたはScratchで実行
   player.getPos()
   ```
   プレイヤーの座標が返されれば接続成功です。

3. **最初のブロック配置**
   ```javascript
   world.setBlock(100,64,100,minecraft:diamond_block)
   ```

### Scratchでの基本操作

1. **Scratch環境の起動**
   - ブラウザで `http://localhost:8601` にアクセス
   - Minecraft拡張機能を追加

2. **基本的なブロックの使用**
   ```scratch
   [プレイヤー位置を取得] を [位置] に格納
   [位置] と言う
   ```

3. **ブロック配置の実行**
   ```scratch
   座標 (100, 64, 100) に [minecraft:stone] を配置
   ```

## Scratchでのプログラミング入門

### レッスン1: プレイヤーの位置を調べよう

**目標**: プレイヤーの現在位置を取得して表示する

```scratch
緑の旗がクリックされたとき
  繰り返し
    [プレイヤー位置を取得] を [現在位置] に格納
    [現在位置] と [2] 秒言う
    [3] 秒待つ
```

**応用**: 座標を分解して表示
```scratch
緑の旗がクリックされたとき
  [プレイヤー位置を取得] を [位置データ] に格納
  [位置データ] の [1] 番目を [X座標] に格納
  [位置データ] の [2] 番目を [Y座標] に格納
  [位置データ] の [3] 番目を [Z座標] に格納
  [X: ] と [X座標] と [ Y: ] と [Y座標] と [ Z: ] と [Z座標] を結合したものと言う
```
